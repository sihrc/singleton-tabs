# Changelog

All notable changes to Singleton Tabs are documented here.

The project follows [Semantic Versioning](https://semver.org/).

## 0.1.0

- Added configurable HTTP(S) URL-prefix singleton rules.
- Added per-window and profile-wide singleton scopes.
- Added optional canonical-tab organization by rule order.
- Added an intentional duplicate action in the extension popup.
- Added Gmail and Google Calendar starter rules for fresh installs.
- Added local-only storage, restart recovery, and bounded error reporting.
- Added automated tests and static checks for permissions, remote code, and
  network surfaces.
